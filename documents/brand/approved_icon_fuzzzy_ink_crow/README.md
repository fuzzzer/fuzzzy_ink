# Fuzzzy Ink: the approved crow icon (image only)

**Approved by the owner on 2026-09-28** ("give me grip B as approved"). This is the image only. **It is not wired into the app:** the app's current launcher icon is unchanged.

A black crow flies left across the red Fuzzzy sun, carrying a cream envelope pinched by its corner in its beak. The envelope's wax seal is a hole showing the red sun.

| File | What |
|---|---|
| `master.svg` | The vector master: a 2048 canvas of plain filled paths (ground `#0b0c0f`, sun `#b2261d` as an exact disc of radius 750, the crow in ink, the envelope in paper `#f2f0e9`). No strokes, clips, gradients or text. |
| `master_2048.png`, `master_1024.png` | Renders of the master, night skin. |

**How it was made:**
- It starts from the owner-approved crow with the sealed letter, made in the Fuzzzy Motion Studio's Ink project.
- It was refined with Nano Banana Pro (Higgsfield) in two rounds: smoother wings and tail, then the letter held in the beak. Grip B was chosen.
- It was traced back to vector with the exact approved sun.
- Full record: `~/programming/marketing_studio/full_creativity/higgsfield_motion/brand/apps/ink_crow_v2/README.md`.

**To use it as the app icon later:**
- It has to go through the app's icon pipeline: the brand-kit exports and `flutter_launcher_icons*.yaml` / `scripts/ios_app_icons.py`, as those files explain.
- A paper-skin version is still to be made.
- Only do this when the owner decides to change the app icon.
